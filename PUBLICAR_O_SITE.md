# Publicação de Os Quatro Ís

Este repositório foi inicializado para habilitar a branch `main` nas configurações do GitHub Pages.

## Próximo passo

1. Baixe e extraia o pacote `Os_Quatro_Is_Site_GitHub_Pages_v1.zip` fornecido na conversa.
2. No repositório, abra **Add file → Upload files**.
3. Envie **os arquivos de dentro** do ZIP, de forma que `index.html`, `app.js` e `styles.css` fiquem na raiz; preserve a pasta `assets/`.
4. Confirme em **Commit changes**.
5. Abra **Settings → Pages → Build and deployment** e escolha **Deploy from a branch**; depois selecione a branch `main` e a pasta `/(root)` e clique **Save**.

**Observação:** o PDF oficial ainda não está incluído. Para habilitar o leitor de regras, adicione `assets/Os_Quatro_Is_Livro_de_Regras_v2_2.pdf`, sem alterar seu conteúdo.

O nome do repositório é `RPG-4IS`, portanto o endereço previsto do Pages é `https://grisoote.github.io/RPG-4IS/`.
